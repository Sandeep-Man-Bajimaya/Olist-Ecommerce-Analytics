Database 
Schema Notes
1. Customers → Orders
   Connection: customer_id
   Relationship: One-to-Many
   One customer can have multiple orders.

2. Orders → Order Items
   Connection: order_id
   Relationship: One-to-Many
   One order can contain multiple order items.

3. Orders → Order Payments
   Connection: order_id
   Relationship: One-to-Many
   One order can have multiple payment records.

4. Orders → Order Reviews
   Connection: order_id
   Relationship: One-to-Many
   One order can have multiple review records.

5. Order Items → Products
   Connection: product_id
   Relationship: Many-to-One
   Multiple order items can refer to the same product.

6. Order Items → Sellers
   Connection: seller_id
   Relationship: Many-to-One
   Multiple order items can be associated with the same seller.

7. Products → Category Translation
   Connection: product_category_name
   Relationship: Many-to-One
   Multiple products can belong to the same product category.

8. Customers → Geolocation
   Connection: customer_zip_code_prefix = geolocation_zip_code_prefix
   Relationship: To be verified from the data.
   Geolocation contains multiple records for some ZIP-code prefixes.

9. Sellers → Geolocation
   Connection: seller_zip_code_prefix = geolocation_zip_code_prefix
   Relationship: To be verified from the data.
   Geolocation contains multiple records for some ZIP-code prefixes.
